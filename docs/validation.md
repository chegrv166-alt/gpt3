# Проверка первого вертикального среза

Проверено 1 ноября 2026 года в текущей облачной среде, Python 3.12.14. Это проверка программных контрактов и наблюдаемого поведения, не валидация психологической достоверности модели.

- Установка: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -e ".[dev]"` — успешно, без наследования системных пакетов.
- `.venv/bin/python -m pytest -q` — **29 passed**.
- `.venv/bin/python -m mypy social_sim` — **10 модулей, ошибок нет**.
- `validate data/fixtures` — 10 явных досье.
- Проверены реальные CLI: run, explain, resume, batch и ошибки входных данных.
- Тесты проверяют продолжение 9+21 дней против непрерывного состояния, собственные знания, несимметричные последствия, отказ, расписание, повтор факта, cooldown и ограничение инициативы одним слотом.

## 30 дней, seed 42

197 инициатив; 92 принятых приглашения; 83 отказа; 19 истёкших приглашений; 3 приглашения остаются ожидающими ответа за границей прогона. 92 встречи; 28 направленных связей изменились. 45 сообщений о встречах, 9 эпизодов дистанции, один вопрос с отдельным ответом. У всех значимых решений есть trace. Все девять NPC совершили социальные действия.

Артефакты: `output/final_42/`. Итоговые метрики: `metrics.json`; пояснение примера: `example_explanation.json`. Каталог output намеренно исключён из Git.

## Наблюдаемая причинная цепочка

- `e000315` (слот 58): n4, n2 встретились.
- `e000336` (слот 62): n2 сообщил об этом n3.
- `e000346` (слот 63): n3 спросил n4 о ситуации. У его интерпретации есть ссылка на исходную встречу; решение хранит оценки альтернатив.
- `e000347` (слот 63): адресат самостоятельно выбрал ответ; это отдельное событие и отдельный trace.

Для просмотра: `python -m social_sim explain --run output/final_42 --event-id e000346`.

- Инициативы: 197–216 на прогон.
- Отказы: 83–102 на прогон.

## Обзор и исправления

Независимый обзор нашёл повреждённые планы и ссылки traces, нестрогие шкалы, необработанный OverflowError состояния RNG и автоматическое облегчение обиды без ответа. Все исправлены с регрессионными тестами. Дополнительно проверяются соответствие внешнего trace действию и одна инициатива за слот. Тест влияния цели независимости обнаружил неиспользуемый приоритет; он теперь участвует в отдыхе и цене инициативы.
