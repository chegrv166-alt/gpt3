# План первого среза

Цель: автономные встречи и объяснимые субъективные последствия. Спецификация: `project-brief.md`; решения: `architecture.md`.

Ограничения: Python 3.12+, русская документация, английский API, 24 целочисленных характеристики 0–5, никакого всеведения, ежедневного распада дружбы, сценарной драмы и runtime LLM.

- [x] 1. Написать и запустить тесты загрузки/шкал/ссылок; реализовать модели и десять явно заданных YAML-досье.
- [x] 2. Написать и запустить тесты автономности, приглашений, расписания и traces; реализовать движок, Utility AI и планы.
- [x] 3. Написать и запустить тесты приватности, интерпретаций и памяти; реализовать доставку знаний, вопрос и дистанцию.
- [x] 4. Написать и запустить тесты save/resume, CLI и повреждённых данных; реализовать снимки, журнал и диагностику.
- [x] 5. pytest, mypy --strict, 30 дней seed 42, несколько seed, сравнение с действием игрока; независимый обзор и исправление существенных замечаний.

Особый фокус: bool вместо чисел; несуществующий участник; повторное сообщение; занятое время; повреждённый snapshot и случайность после загрузки.

Порядок реализации согласован прямым поручением пользователя продолжить после проектирования; промежуточное согласование технических решений не требуется. Этапы полного MVP после первого среза перечислены в architecture.md.

## Журнал выполнения

Первичные тесты зафиксировали отсутствие модулей; после реализации — 14 прошедших тестов. Следующие регрессии выявили неограниченную инициативу в слоте, автоматическое облегчение от вопроса, повреждённые snapshots и неиспользуемую цель независимости. Итог: 29 тестов, mypy и реальные прогоны прошли. Подробности и ограничения — validation.md.
